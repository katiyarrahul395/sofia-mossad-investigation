# The Sofia Investigation

A fictional, tongue-in-cheek intelligence-agency questionnaire. It is a joke website, not a real allegation or investigation.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. After GitHub Pages finishes deploying, the public site URL will appear in the Pages section.

Photo areas are intentionally placeholders for now; no pictures have been added.
